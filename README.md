# MTK Private Business Manager

Install the app on your phone: https://mthokobless96-dev.github.io/mtk-private-business-manager/

On Android, open the link in Chrome and choose **Install app** or **Add to Home screen**. On iPhone, open it in Safari, tap **Share**, then **Add to Home Screen**. Open it once while online before using it offline.

Choose Sky blue, Teal, or Dark from **Settings**. The app stores business records on this device and encrypts them with your app password. Save the one-time recovery key shown on first setup; Settings can create or replace it later. If you forget your password, use the key on the unlock screen to reset it on this device. If you lose both, records cannot be recovered. JSON backup files are not encrypted; keep them private.
